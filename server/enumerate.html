Relay discovery

Same passive-discovery approach sites like nostrwat.ch use: watches a handful of well-known bootstrap relays (relay.damus.io, relay.primal.net, purplepag.es) for events that name other relays — NIP-65 relay lists (kind:10002) and NIP-66 relay discovery records (kind:30166) — and collects the distinct URLs. Bounded to a 30-second scan; does not recursively crawl newly-found relays for more relays.

Identity enumeration

For each relay in the set below, requests every kind:0 profile it has and collects distinct pubkeys — the same thing an unauthenticated REQ {"kinds":[0]} already reveals from any single relay, just aggregated across several. Uses the relay list from the last relay scan above if one has run; otherwise falls back to the bootstrap set. Capped at 20 relays and a 30-second budget per scan — a bounded sample, not an exhaustive crawl of any relay's full history. The total count reflects every distinct pubkey actually seen; only the first 500 are listed below.
