What this counts, honestly: unique relay WebSocket connections to NOSTRAS's own node — not unique visitors. Country is looked up from the connecting IP address at request time only; the IP itself is never stored, only the resulting country code. This is the exact same connection data our own operator dashboard uses internally — nothing here is a separate, curated number.
