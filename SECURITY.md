# Security

Please report vulnerabilities privately to **hello@nostras.app**, or by a
NIP-17 direct message to the NOSTRAS maintainer, not in a public issue.

Include what you found, how to reproduce it, and what you think the impact
is. You'll get a reply within a few days, and credit in the fix unless you
prefer otherwise.

NOSTRAS never holds users' keys or funds. Reports about anything that
could leak key material, send a payment without an explicit user action,
or make the client reach private or local network addresses are treated
as the highest priority.
